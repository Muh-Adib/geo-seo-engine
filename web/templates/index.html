Performa Google Search Console

Data metrik organik langsung dari Google Search Console menggunakan otentikasi Google Cloud Service Account resmi.

Service Account JSON Belum Dikonfigurasi

Untuk menampilkan data klik, tayangan, dan ranking kata kunci riil dari Google Search Console, Anda perlu memasukkan credentials Service Account Google di pengaturan situs:

  1. Buka Google Cloud Console → Buat Service Account → Unduh JSON Key.
  2. Buka Google Search Console → Settings → Users & permissions → Tambahkan email Service Account sebagai Full User.
  3. Buka tab Situs & Jaringan → Klik Pengaturan pada kartu brand Anda → Tempelkan isi JSON Key tersebut.
