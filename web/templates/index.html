Panduan Onboarding Awal (Orang Awam Friendly)

Langkah 1: Hubungkan Akun Gemini

Karena Anda menggunakan Mac ini, sistem secara otomatis mendeteksi sesi login Antigravity Desktop Anda (proofingunipics@gmail.com). Anda juga bisa menambahkan akun Google kedua/ketiga di tab "Akun Gemini" untuk rotasi kuota otomatis.

Langkah 2: Setup Brand Website Anda

Daftarkan website WordPress Anda satu per satu dengan mengklik tombol "+ Tambah Brand Baru". Masukkan nama brand dan alamat domain WordPress Anda.

Langkah 3: Pasang Plugin di WordPress

Unduh plugin WordPress jembatan unicam-seo-bridge.zip. Di WordPress Admin target, buka menu Plugins -> Add New -> Upload Plugin, lalu klik Aktifkan. Plugin ini otomatis menyetel 50 tag dan gambar thumbnail tanpa error Wordfence.

File zip tersedia di folder: wordpress-plugin/unicam-seo-bridge.zip

Langkah 4: Tulis & Terbitkan Artikel!

Pilih brand, layanan, dan kota di tab "Matrix Writer & Preview". Klik Generate 12-Block Preview untuk melihat hasilnya secara instan, lalu klik Publish to WordPress. Artikel langsung tayang dengan 50 tag dan thumbnail Gemini!
